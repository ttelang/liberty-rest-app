== Overview

This project demonstrates a simple REST application using Open Liberty, MicroProfile 6.1, and Jakarta EE 10. It provides a basic Hello World REST endpoint and showcases how to use Liberty Maven plugin for building and running Java microservices.

== Prerequisites

* JDK 17
* Maven 3.8+
* Docker (optional, for containerization)

== Development Environment

This project includes a GitHub Codespace configuration with:

* JDK 17 and JDK 21 via SDKMAN
* Maven build tools
* VS Code extensions for Java, MicroProfile, and GitHub Copilot

----

----

== Running the Application

=== Using Liberty Maven Plugin

[source,bash]
----
mvn liberty:dev
----

This will start Liberty in development mode, with hot reloading enabled.

=== Accessing the Application

Once the server is running, you can access:

* REST Endpoint: http://localhost:5050/liberty-rest-app/api/hello
* Welcome Page: http://localhost:5050/liberty-rest-app/

== Docker Support

The project includes a Dockerfile for containerization:

[source,dockerfile]
----
FROM icr.io/appcafe/open-liberty:full-java17-openj9-ubi

COPY --chown=1001:0 target/liberty-rest-app.war /config/apps/
COPY --chown=1001:0 src/main/liberty/config/server.xml /config/

RUN configure.sh

HEALTHCHECK --interval=10s --timeout=3s CMD curl -f http://localhost:9080/health/ || exit 1

EXPOSE 9080 9443
----

=== Building and Running with Docker

[source,bash]
----
# Build the application first
mvn clean package

# Build the Docker image
docker build -t liberty-rest-app:1.0 .

# Run the container
docker run -d -p 5050:9080 -p 9443:9443 --name liberty-rest-app liberty-rest-app:1.0

# Check container logs
docker logs -f liberty-rest-app

# Stop and remove the container when done
docker stop liberty-rest-app
docker rm liberty-rest-app
----
